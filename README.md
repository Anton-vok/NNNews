# NNNew
## О чем этот проект
Это бот для рассылки новостей о мероприятиях связанных с вузом, с фильтрацией по интересам и доступности мероприятия для студента. В будущем планируется добавление раслыки опросов для помощи в сборе информации для курсовых проектов.
## Запуск проекта
1. Запустить `setup.sh`
   ```
   bash ./setup.sh
   ```
2. Вставить в `.env` api ключ от тг бота
   ```
   TELEGRAM_BOT_TOKEN=
   ```
3. Запустить `main.py`
